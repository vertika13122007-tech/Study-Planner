# Study-Planner
An interactive study planner built with HTML, CSS and JavaScript to organize task, track , modify and gamify your daily routine.
<br>
<br>
<h2>Features : </h2>
<p>- ➕ Add new tasks with a clean input box
<br>- ✅ Mark tasks as complete (strike-through effect)
<br>- ✏️ Edit tasks inline
<br>- ❌ Delete tasks instantly
<br>- 🔵 Category dot selector (Assignment, Exam, Personal)
<br>- 📊 Live progress bar with percentage tracking
<br>- 🎨 Pastel UI with responsive layout and smooth transitions</p>
<br>

<h2>How It Works : </h2>
Each task card includes:
<br>- A white circle dot (clickable) to assign a category
<br>- Task text with action buttons (✔ ✏️ ❌)
<br>- A progress bar at the bottom that updates as tasks are completed
<br>
